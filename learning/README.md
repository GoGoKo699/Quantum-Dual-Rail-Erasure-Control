# Learning route

A dual-rail qubit stores an unknown state in the position of a single
excitation. The vacuum flags loss. When the two rails decay at different
rates, even a surviving excitation carries evidence about its initial rail.
The project asks how quickly a bounded coherent coupling can remove that
state dependence and what survival it can guarantee at any deadline.

- Start with the [Watrous bridge](WATROUS_BRIDGE.md) for the channel
  description and a worked example.
- Follow the [30 milestones](MILESTONES.md) from the physical model to the
  exact finite-time frontier, terminal filtering and calibration.
- Read the [model](../science/model.md), [frontier proof](../science/frontier.md)
  and [robustness analysis](../science/robustness.md) for precise hypotheses
  and derivations.

The single educational anchor is John Watrous's *The Theory of Quantum
Information* (Cambridge University Press, 2018). The bridge identifies the
relevant sections. The [related-work account](../references/RELATED_WORK.md)
credits the experimental and mathematical results used in the science.
