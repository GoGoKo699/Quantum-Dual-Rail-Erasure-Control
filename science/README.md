# Scientific account

1. [Dual-rail loss and the erasure channel](model.md) defines the physical input, admissible controls and output channel. It shows how the product of the two input survival eigenvalues stays fixed across waveforms of the same duration.
2. [Optimal synthesis at a fixed deadline](frontier.md) gives the pulse, proves its optimum over time-dependent controls, and constructs the optional terminal filter. An elementary argument separately checks the exact speed limit.
3. [Calibration and hardware scale](robustness.md) tests what changes when the nominal pulse and the actual dynamics differ. It gives a hardware-scale calculation based on published parameters.

Use [related work](../references/RELATED_WORK.md) for the relationship to existing dual-rail control and hyperbolic geometry, and [verification](../verification/README.md) for runnable finite checks.
